Text Inputs

Single-line text inputs with all variants, sizes, and states. Uses the same data-input attribute pattern as your buttons.

Variants

Each variant mirrors a button variant. Use primary for default, info for a tinted accent, and the rest for semantic meaning.

Sizes

Three sizes that match the button scale (sm / md / lg).

States

Default, focus (use Tab to test), disabled, readonly, and [data-state] validation states.

Textarea

Multi-line text with the same variant and state system. Vertically resizable by default.
